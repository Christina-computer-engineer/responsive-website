# Responsive Website Using CSS Media Queries

## Objective

Convert a desktop-only webpage into a mobile-friendly layout using CSS Media Queries.

## Technologies Used

* HTML5

* CSS3

* Media Queries

## Features

* Responsive navigation menu

* Mobile-friendly layout

* Cards stack vertically on small screens

* Flexible design using Flexbox

* Tested on mobile viewport

## Files

* index.html

* style.css

## Media Query Used

```css
@media (max-width:768px)
```

## Learning Outcome

* Understanding CSS Media Queries

* Mobile-first design concepts

* Responsive layouts

* Flexbox for adaptive designs
